# SharePoint Team Portal Builder — How to Use

## What is this?

A reusable Amazon Quick skill that builds a **complete, themed team portal on SharePoint** for you. It generates 10-17 premium HTML pages with magazine-quality design, uploads them to your SharePoint site, and gives you a step-by-step guide to go live.

No coding or design skills needed. Just answer the questions and the skill handles the rest.

---

## What you get

- **Home page** — hero banner, quick links grid, welcome card, latest highlights
- **Sub-pages** — pick from 17 page types (team roster, policies, tools, training, time off, engagement, wellbeing, forms, newsletter, celebrations, and more)
- **Brand assets** — AI-generated team logo, hero banner, and optional mascot
- **5 color themes** — Neon Dark, Corporate Light, Ocean Dark, Sunset Warm, Forest, or your own custom colors
- **Deployment guide** — exact URLs and iframe heights for every page, plus manual steps for theme and navigation
- **Easy updates** — replace an HTML file in the document library and the page updates automatically

---

## Before you start

You need:

1. **An existing SharePoint site** for your team (e.g. `https://amazon.sharepoint.com/sites/Your-Team`)
2. **Edit permissions** on that site
3. **Amazon Quick desktop** with the SharePoint connector enabled
4. Your team info ready:
   - Team name and slogan
   - Core values or pillars (3-5 words)
   - Team roster (names, aliases, roles)
   - Any existing docs you want to include (policies, training materials, wiki, etc.)

---

## How to run it

### Option A — Just ask

Open Amazon Quick and say:

> **"Build a team portal for my team on SharePoint"**

The skill activates automatically. It will walk you through:
1. **Team identity** — name, slogan, pillars, roster
2. **SharePoint details** — site URL, folder name
3. **Color scheme** — pick a preset or go custom
4. **Page selection** — choose which pages you want
5. **Content gathering** — provide policies, tools, training info etc.
6. **Generation** — it builds all the HTML pages and previews them
7. **Upload** — uploads everything to your SharePoint document library
8. **Deployment guide** — gives you exact steps to embed each page

### Option B — With an agent

If you have a custom agent, add this skill to it:
- In Amazon Quick → your agent → Skills → add `sharepoint-team-portal`

---

## After the skill runs

You'll have HTML files in your SharePoint document library. To go live:

1. **Edit** each SharePoint page
2. Add an **Embed** web part
3. Paste the URL from the deployment guide
4. Set the height
5. **Republish**

Then:
- Set a **dark theme** on your site (if using a dark color scheme)
- Add **sidebar navigation** links to each page
- Upload your **team logo** as the site logo

The deployment guide includes all of this step by step.

## Tips

- **Bring your docs.** If you already have a wiki, handbook, policy doc, or roster spreadsheet, attach them in chat. The skill extracts content directly — saves you typing everything out.
- **Start with core pages.** You can always add more later.
- **Updating content is easy.** Just replace the HTML file in the document library. No need to touch the SharePoint page.
- **The home page sets the style.** All other pages automatically match it.
